# 1. 文档说明

## 1.1 文档目的

本文档定义 AStockQuant 系统测试策略和测试规范。

目标：

- 保证系统功能正确；
- 保证数据准确；
- 保证计算模型可靠；
- 保证系统长期稳定运行。

---

# 2. 测试目标

测试重点：

## 功能正确性

验证：

- 数据采集；
- 数据存储；
- 指标计算；
- 股票评分。


---

## 数据准确性

确保：

- 外部数据正确；
- 转换过程正确；
- 计算结果正确。


---

## 系统稳定性

验证：

- 长时间运行；
- 大数据量处理；
- 异常恢复。


---

## 9.2 ROE测试


公式：

```text
ROE =
净利润 / 平均净资产
```


测试：

输入：

```text
净利润=100

净资产=500
```


结果：

```text
ROE=20%
```
