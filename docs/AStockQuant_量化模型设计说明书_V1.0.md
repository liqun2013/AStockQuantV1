# 1. 文档说明

## 1.1 文档目的

本文档定义 AStockQuant 量化分析模型设计方案。

目标：

- 建立股票价值分析体系；
- 实现投资逻辑模型化；
- 将投资经验转化为可计算规则；
- 支撑自动化股票筛选。


---

## 1.2 模型定位

AStockQuant不是：

- 高频交易系统；
- 短线预测系统；
- 自动买卖系统。

定位：

> 基于企业基本面和估值分析的长期投资辅助系统。

# 4. 指标体系设计


指标分为：

- 成长指标；
- 盈利指标；
- 财务健康指标；
- 估值指标；
- 现金流指标。


---

# 4.1 成长指标


## 营收增长率


公式：

```
Revenue Growth =
(本期收入-同期收入)/同期收入
```


权重：

20%

---

## 净利润增长率


公式：

```
Profit Growth
=
净利润同比增长
```

权重：

20%

---

# 4.2 盈利能力指标


## ROE


公式：

```
ROE=
净利润/平均净资产
```


意义：

衡量企业赚钱能力。


---

## 毛利率


公式：

```
Gross Margin
=
毛利润/营业收入
```


---

# 4.3 财务健康指标


包括：

- 资产负债率；
- 经营现金流；
- 自由现金流。


---

# 4.4 估值指标


包括：

- PE；
- PB；
- 股息率。

# 8. 综合评分模型设计


综合评分：

```
Total Score

=

Fisher Score × 40%

+

Buffett Score × 40%

+

Graham Score × 20%
```


---

# 8.1 权重说明


长期投资：

更加关注：

- 企业质量；
- 成长能力。


因此：

Fisher + Buffett

占80%。

---

# 9. 评分算法设计


## 9.1 标准化
