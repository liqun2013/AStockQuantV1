# AStockQuant

AStockQuant is an A-share quantitative investment research platform based on Fisher growth, Buffett quality, and Graham value principles.

## Foundation

- .NET 10
- ASP.NET Core
- SQL Server 2019
- Dapper
- AKTools
- Bootstrap

## Architecture

Domain → Application → Infrastructure → Web

The foundation phase establishes project boundaries and contracts. Investment factors, data ingestion, valuation, screening, and backtesting will be added in subsequent phases.
